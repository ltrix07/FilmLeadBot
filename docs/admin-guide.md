# Гайд по админ-панели бота

Этот гайд — для администратора бота (тебя). Здесь описано, как пользоваться
панелью управления: спонсоры, кампании, коды фильмов, партнёры, рассылки.

## Как открыть админ-панель

Напиши боту команду `/admin`. Появится меню с разделами:

- 📡 **Спонсоры**
- 📢 **Кампании**
- 🎬 **Коды**
- 👥 **Партнёры**
- 📣 **Рассылка**

Доступ к `/admin` есть только у тех, чей Telegram ID указан в настройках
бота как администраторский.

Почти в любой форме, где бот просит что-то прислать (число, дату, название
и т.п.), внизу есть кнопка **❌ Отмена** — можно в любой момент выйти без
сохранения.

## 📡 Спонсоры

Спонсор — это канал или группа, на которые бот требует подписаться перед
использованием.

**Добавить спонсора:**
1. «➕ Добавить спонсора».
2. Нажми «📢 Выбрать канал» или «👥 Выбрать группу» — откроется список твоих
   чатов, выбери нужный. Либо перешли боту любое сообщение из этого чата,
   либо пришли его числовой chat_id вручную.
3. **Бот должен уже быть добавлен в этот канал/группу заранее** (для канала
   — с правами администратора, иначе бот не сможет проверять подписки).
4. Пришли постоянную инвайт-ссылку на чат (или `-`, если у канала есть
   публичный username — тогда ссылка не нужна).

Список спонсоров показывает статус: «✅ доступен» — бот может проверять
подписки, «⚠️ нет доступа» — бота нужно добавить в чат заново или вернуть
ему права администратора.

## 📢 Кампании

Кампания — это план «привести N подписчиков на конкретный спонсорский
канал». Пользователь засчитывается в кампанию в момент, когда реально
проходит проверку подписки — не когда просто подписался.

**Создать кампанию:**
1. «➕ Новая кампания» → выбери спонсора из списка.
2. Укажи лимит (сколько пользователей нужно набрать).
3. Укажи, когда запускать: `сейчас` — сразу активна, или дата и время в
   формате `25.12.2026 18:00` (по UTC) — запустится автоматически сама.

**Карточка кампании** (нажми на кампанию в списке) показывает счётчик
«засчитано / лимит» и статус. Оттуда можно:
- ✏️ **Изменить лимит** — если новый лимит меньше уже засчитанного, бот
  предупредит и завершит кампанию с фактическим результатом.
- ▶️ **Возобновить** — если кампания встала из-за потери доступа бота к
  каналу (появляется только когда доступ восстановлен).
- 🚫 **Отменить кампанию** — необратимо.

Кампания завершается автоматически, когда счётчик достигает лимита — тебе
придёт уведомление. Уведомление также приходит, если бот теряет доступ к
каналу спонсора (кампания при этом ставится на паузу со статусом «error»,
пока не восстановишь доступ).

## 🎬 Коды

Коды фильмов — то, что пользователь присылает боту, чтобы получить
название. Ведущие нули в кодах (например `00123`) сохраняются как есть.

- 🔍 **Найти код** — посмотреть карточку конкретного кода (название,
  статус, дата создания/изменения), оттуда же можно изменить название,
  деактивировать/восстановить код и посмотреть историю изменений.
- ➕ **Добавить код** — вручную, одним кодом.
- 📄 **Шаблон для импорта** — скачать пустой `.xlsx` с примером заполнения
  (колонки `operation`, `code`, `title`; `operation` — `upload`, чтобы
  создать/обновить код, или `delete`, чтобы деактивировать).
- 📥 **Скачать текущие коды** — выгрузка ВСЕХ уже добавленных кодов (включая
  деактивированные, со статусом) в `.xlsx` — удобно, чтобы посмотреть, что
  уже есть в базе, перед тем как готовить новый файл на импорт.
- 📤 **Загрузить файл** — массовая загрузка `.csv` или `.xlsx` с колонками
  `operation, code, title`. Бот покажет план изменений (сколько создастся,
  восстановится, деактивируется, и конфликты — где код уже существует с
  другим названием) и попросит подтвердить перед применением.

## 👥 Партнёры

Партнёр — доверенный человек, который приводит пользователей по своей
реферальной ссылке и видит статистику, но освобождён от обязательной
подписки на спонсоров.

**Добавить партнёра:**
1. «➕ Добавить партнёра».
2. Нажми «👤 Выбрать пользователя» и выбери из списка, либо перешли его
   сообщение, либо пришли его числовой telegram_id вручную. **Важно:**
   пользователь должен был хотя бы раз запустить бота (`/start`) — иначе
   бот его ещё не знает.
3. Партнёру нужно написать боту слово **«партнер»** (или «партнёр») обычным
   текстом — это активирует его личный кабинет. Слово специально не
   привязано к кнопке или команде — это скрытый способ активации, доступный
   только тем, кого ты добавил.

В кабинете партнёр получает свою реферальную ссылку, статистику (сколько
привёл / сколько прошли обязательные подписки) и может скачать файл с
активными кодами.

«🚫 Отозвать» рядом с партнёром в списке — отключает кабинет; повторное
добавление того же человека снова его активирует с тем же реферальным кодом.

## 📣 Рассылка

- 📝 **Новая рассылка** — пришли любое сообщение (текст, фото с подписью —
  что угодно), бот покажет превью и число получателей (все пользователи,
  которые не заблокировали бота). Дальше выбор:
  - 🚀 **Отправить сейчас** — рассылка запускается сразу.
  - 🕒 **Запланировать** — укажи дату и время (`25.12.2026 18:00`, UTC),
    рассылка уйдёт автоматически в указанный момент.
- 🕒 **Запланированные** — список ещё не отправленных запланированных
  рассылок, с возможностью отменить любую до момента отправки.

По завершении рассылки (сразу или по расписанию) тебе придёт итог: сколько
доставлено, сколько нет (обычно это те, кто заблокировал бота).

## Как это выглядит для обычного пользователя

1. Пользователь запускает бота (`/start`), в том числе может прийти по
   партнёрской ссылке.
2. Если он не партнёр — бот требует подписаться на все активные кампании
   (спонсорские каналы/группы) и заново проверяет это при каждом действии.
3. После прохождения проверки пользователь может присылать боту код фильма
   текстом и получать название.

Партнёры (после активации словом «партнер») этот шаг с подпиской не видят —
у них сразу открыт и обычный функционал, и личный кабинет.
